## Sobre o Projeto

Componente de **card NFT** desenvolvido utilizando **HTML e CSS**.
Este projeto foi criado com o objetivo de praticar conceitos fundamentais de **layout com Flexbox**, além de explorar efeitos visuais com pseudo-elementos.

Baseado em um desafio do **Frontend Mentor**.

---

##  Tecnologias Utilizadas

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge\&logo=html5\&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge\&logo=css3\&logoColor=white)

---

## Conceitos Aplicados

* Layout com Flexbox
* Pseudo-elementos (`::before`)
* Pseudo-classes (`:hover`)
* Organização de estilos com CSS
* Construção de componentes visuais

---

## Responsividade

O projeto foi desenvolvido para **diferentes tamanhos de tela**,
adaptando-se a dispositivos desktop e mobile.

---

## Desafios Enfrentados

Durante o desenvolvimento, os principais desafios foram:

* Aplicar corretamente os pseudo-elementos para criar efeitos visuais
* Implementar o efeito de overlay na imagem utilizando `hover`
* Inserir ícones antes de informações como valor em ETH e tempo restante

Esses desafios foram importantes para aprofundar o conhecimento em **CSS avançado** e manipulação visual.
